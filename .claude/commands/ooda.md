Work through the following using the OODA loop:
1. **Observe** — the raw facts/constraints, no interpretation yet
2. **Orient** — what these facts mean given the context/goal; name assumptions explicitly
3. **Decide** — the chosen approach and the alternatives it beat, briefly
4. **Act** — the concrete next step(s), specific enough to execute immediately

Use this for genuinely complex, multi-factor problems only — don't pad a simple question into four sections.
